Пятая лабораторная работа по предмету "Web-технологии": HTML-страница "О себе" (1 вариант: "Студент-разработчик")

Используемые технологии:
1. HTML5
2. CSS3
3. JavaScript
4. Visual Studio Code
5. GitHub

Структура HTML:
1. header – шапка с моим именем/фамилией и заголовком страницы
2. main – основной контент
3. Навигационное меню и карточки моих проектов в ряд
4. Галерея скриншотов моих проектов
5. Cписок навыков как сетка карточек-плиток
6. aside – боковая панель с краткой информацией (мои любимые технологии)
7. footer – подвал с копирайтом и годом
8. Одно изображение (аватар) с атрибутами src, alt, width, height
9. Форма обратной связи: поля «Имя», «Email», «Сообщение», и кнопка отправки
10. Цветовая гамма: сине-белая

Структура CSS:
1. Основной стиль – во внешнем файле
2. CSS переменные в :root, body.theme-light, body.theme-dark для цветов и шрифтов
3. Примеры позиционирования: static, relative, absolute
4. Состояния элементов: :hover, :active, :focus, :visited
5. Flexbox (навигационное меню и карточки проектов) и Grid (скриншоты и навыки)
6. Медиа-запросы для планшетов и телефонов

Структура JS:
1. Ввод/вывод - prompt (имя), alert (приветствие), console.log
2. Условные конструкции и циклы
3. Функции для поиска максимума, фильтрации и подсчёта суммы в массиве
4. Функции создания, добавления, удаления, скрытия/показа и сохранения проектов
5. checkElement - функция обработки ошибок
7. switchTheme - функция для смены темы
8. restoreState - функция сохранения состояния
9. Функция загрузки DOM

Как запустить:
1. Скачайте или клонируйте репозиторий
2. Откройте файл index.html в любом браузере
